# Scheda della postazione di laboratorio

## Hardware

La postazione utilizza un PC con Windows 11, processore Intel i7 e 16 GB di memoria RAM.

Il computer dispone delle periferiche necessarie per seguire le esercitazioni e salvare i file nel repository personale.

### Identificazione della postazione

La postazione viene identificata dal numero assegnato dal laboratorio. Il numero va controllato prima di iniziare il lavoro.

## Software installato

Per scrivere e verificare i documenti uso Visual Studio Code e la sua anteprima Markdown.

Sono disponibili anche JDK 17, Git 2.4x e Python con il supporto locale per i notebook `.ipynb`.

## Credenziali di accesso

Uso un account GitHub personale per collegarmi al repository del corso. La password non viene riportata in questo documento.

I notebook vengono aperti e verificati localmente con un kernel Python. Le credenziali restano memorizzate soltanto negli strumenti autorizzati.
